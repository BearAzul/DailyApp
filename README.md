### Daily App

DailyApp adalah aplikasi berbasis web modern berupa platform social media sederhana yang dibangun menggunakan framework Next.js. Aplikasi ini dirancang untuk keseharian seperti memposting gambar, kalimat, atau lainnya.

### Fitur
* **Server-Side Rendering (SSR):** Dibangun dengan Next.js, aplikasi ini mendapat manfaat dari pra-render halaman di server untuk performa dan SEO yang lebih baik.
* **Integrasi Database:** Memanfaatkan Prisma, sebuah ORM generasi berikutnya, untuk akses database yang lugas dan aman.
* **UI Modern & Dapat Digunakan Kembali:** Proyek ini diatur dengan Tailwind CSS dan **shadcn/ui**, menyediakan koleksi komponen UI yang dapat disesuaikan.
* **Dukungan TypeScript:** Seluruh basis kode ditulis dalam TypeScript, memberikan keamanan tipe (*type safety*) dan pengalaman pengembang yang lebih baik.
* **Font yang Dioptimalkan:** Menggunakan `next/font` untuk memuat keluarga font Geist.
